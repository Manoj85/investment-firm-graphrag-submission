# Packaged code map

Read-only Graphify snapshot of application Python source, built October 19, 2026. This code graph is separate from the organizational knowledge graph used by the RAG workflow. The snapshot is static; regenerate after implementation changes.

Graphify 0.9.92 generated graph.json and the viewer HTML with code-only extraction and clustering disabled. The pinned vis-network 9.1.6 JavaScript is inlined so viewing requires no CDN request. snapshot.json records build counts, provenance and checksums. Runtime does not install or invoke Graphify.

Graphify: https://github.com/Graphify-Labs/graphify (Apache-2.0/MIT; accompanying license and notice files retained).
vis-network: https://github.com/visjs/vis-network (Apache-2.0 or MIT; accompanying licenses retained, plus embedded distribution notices).

Only the repository-owned graph.html is rendered. Do not replace it with uploaded files or model-generated HTML. Source paths inside the graph are relative to scripts/. Static inferred edges require verification against the code.

Embedding adjustment: selecting a node fits its immediate neighborhood to the available iframe width instead of using a fixed zoom. Graph contents and relationships are unchanged.
